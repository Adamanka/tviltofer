# TVILTOFER

Сайт: https://adamanka.github.io/tviltofer/
Репозиторий: https://github.com/Adamanka/tviltofer

Статический сайт на HTML, CSS и JavaScript с Pico CSS. Сборка и установка пакетов не требуются. Оформление и сценарии вынесены в отдельные файлы.

## Файлы

- `index.html` — структура страницы, тексты и адреса аккаунтов.
- `styles.css` — оформление, адаптивная вёрстка, лианы, цветение, мерцание и реакции кнопок.
- `script.js` — голубое пламя, мобильные переходы, световая волна и запуск цветения. Подключён с `defer`, чтобы выполняться после разбора страницы.
- `assets/truetypewriter-polyglott.woff2` — предоставленный шрифт в веб-формате.
- `assets/truetypewriter-license.txt` — его лицензия SIL OFL 1.1.
- `assets/hero.png` — исходный арт 2560 × 1305; сохранён без изменений.
- `assets/hero.webp` — облегчённая версия того же арта. Браузер выбирает её через `<picture>`, PNG служит запасным вариантом.

WebP занимает 303 548 байт вместо 3 270 217 байт PNG: размер изображения уменьшен примерно на 91%. Это сравнение файлов, а не замер времени загрузки. Pico CSS загружается с jsDelivr; для его получения нужен интернет.

## Как обновить сайт

1. Откройте `index.html` в репозитории и нажмите кнопку редактирования. Текст и адреса аккаунтов находятся в обычных HTML-блоках. Для оформления редактируйте `styles.css`, для поведения — `script.js`.
2. Сохраните изменения в ветку `main`. GitHub Pages публикует файлы из корня этой ветки.
3. На вкладке Actions дождитесь успешного `pages build and deployment`, затем откройте сайт и проверьте изменённый раздел. Старое изображение может оставаться в кэше браузера.

Для локального просмотра можно открыть `index.html` в браузере или запустить любой локальный статический сервер в папке сайта. Для отката используйте историю нужного файла в GitHub и восстановите проверенную версию.

## Арты

Для галереи требуются три дополнительных оригинальных арта. Сейчас показывается сообщение о пополнении коллекции. Заменителей и выдуманных авторов нет.

Когда арты будут предоставлены, загрузите их в `assets/` и замените сообщение внутри `section#gallery` на изображения. Укажите реальные названия и авторство, содержательный `alt`, исходные `width` и `height`; для изображений ниже первого экрана используйте `loading="lazy"` и `decoding="async"`. Проверьте, что все три файла открываются на опубликованном сайте.

## Что проверять после правок

- Арт расположен выше заголовка, описания и кнопок; исходное изображение и подпись «Designed & Developed by Adaman» сохранены.
- Нет горизонтальной прокрутки на телефоне, планшете и компьютере. Нижние переходы не закрывают подвал.
- Tab подсвечивает выбранную ссылку; «Перейти к содержимому» переносит фокус в основную часть. Пламя работает без отдельной кнопки остановки.
- При системной настройке уменьшения движения пламя не анимируется. Сценарий также приостанавливает его вне экрана и на скрытой вкладке.
- Адреса Twitch, VK, Telegram, Discord, X, DonateX и Boosty соответствуют данным стримера.

Проверены макеты 1920 × 1080, 1366 × 768, 768 × 1024 и 390 × 844 через локальные iframe, а также узкий телефон 320 × 640 и горизонтальный 844 × 390. Это проверка адаптивной вёрстки, а не тест на физических устройствах.
